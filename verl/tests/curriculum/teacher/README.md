# Tests for Teacher Code
Since there are two separate workers which use the teacher model (one for training and one for inference), there are two separate sets of tests. One set deals with the training code (including the saving of checkpoints), and the other set deals with the inference code (including the loading of checkpoints). The `test_special_dp_...` files test the core functionality of the workers while the `test_X_worker.py` files test running the workers inside a Ray WorkerGroup. The file `test_engine.py` is a test of the critic functionality which I was using as a template, and it will be removed eventually. To run any of the tests, execute the comand `python -m pytest <filepath>` from inside this repo's root directory. You will have to install the `pytest` package with pip if it is not installed already.
